# AutoClash

AutoClash 是一款基于 Android 平台的自动化代理组切换工具。它可以根据你当前所处的网络环境（如连接的 WiFi 或者使用的网络运营商），自动调用 Mihomo (Clash Meta) 或 Sing-Box（Clash API 兼容模式）的 API 来切换相应的策略组节点。

## ✨ 核心特性

- **基于环境的智能切换**：
  - **WLAN (WiFi)**：根据当前连接的 WiFi SSID 名称自动切换策略组。
  - **运营商 (ISP)**：根据当前使用的网络运营商（如中国电信、中国联通、中国移动）自动切换策略组。
  - **Fallback（故障转移）**：周期性检测策略组内各节点的连通性，当当前节点不可达时自动切换至下一个可用节点；一旦首个节点恢复，则自动切回。
- **灵活的规则引擎**：支持多条自动化规则、设置规则优先级。

### Fallback 规则说明

Fallback 规则与 WiFi/ISP 规则**不能共存**（同一策略组只能选择其一）。添加时需填写：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 检测地址 | 用于探测连通性的 URL | `http://www.gstatic.com/generate_204` |
| 检测间隔 | 每隔多少秒执行一次完整检测（从第一个节点重新开始） | 60 秒 |
| 重试次数 | 检测失败后的重试次数，0 表示不重试 | 1 次 |
| 重试间隔 | 每次重试之间的等待时间 | 5 秒 |

检测逻辑：按策略组 `all[]` 列表顺序逐个测试 → 找到可用节点立即切换 → 下一个检测周期重新从第一个节点开始，若第一个节点恢复则切回。

## ⚠️ 使用注意

由于 Android 系统的后台限制机制，不同手机厂商（如小米、华为、OPPO、vivo 等）的系统可能会限制应用在后台运行。为确保 AutoClash 能够正常工作，需要将应用的**耗电行为**设置为**完全允许后台运行**。
